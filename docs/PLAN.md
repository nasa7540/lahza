## P1 — المصنع (المصادر أولًا) وفهرس القرآن — 10 ساعات — tags: `p1a-factory-core` ثم `p1-factory`

**موعد 3:00 عصرًا يوم 4، بمعيار آلي:** رمضان وعشاء الفريق متولدتان، الفحوص الآلية تمر، 80% أو أكثر من الادعاءات الدينية مسنودة، وبلا كشف فارغ. إذا تحقق أكمل بلا انتظار.
**الخطة البديلة:** إذا لم يتحقق حتى 6:00 مساءً، أشغّل `factory3.py` (بايثون، من يوم 3) ليكتب المسودات في `journey_drafts`، وأسجّله في الإفصاح، وأكمل P2. المسودات اليدوية آخر خيار.

**P1a — المسار الأدنى (حتى 3:00 عصرًا)**
- فهرس القرآن: سحب 114 سورة من quranenc، تخزين النص العثماني والمطبّع وترجمة رواد، وحساب المتجهات في `quran_verses`. سكربت قابل للاستكمال. `npm run index:quran`.
- عميل النماذج: مهلة فعلية على الطلب كاملًا، إعادة محاولة، مخرجات بمخطط صارم.
- البحث: أدوات (متجهات القرآن بأول 20 وأكثر من صيغة، حديث hadeethenc، موسوعة المصطلحات). النموذج يرجّع مراجع فقط. الكود يسحب، ويُسقط ما ليس صحيحًا أو ما ليس له ترجمة معتمدة بالعربي والإنجليزي والأوردو، ويسجّل.
- تقسيم المصادر لمقاطع مرقّمة بنوعها، ثم استخراج الحقائق المرقّمة.
- الكتابة بالعربي من الحقائق، مع القاعدة التحريرية، واختيار المناسبة من القائمة الثابتة.
- موضوع عشاء الفريق بمشهد جديد: رحلة عمل خارج السعودية، أو أكل من البيت في المكتب.
- التحقق: تصنيف ورقم مقطع. الحذف بحكم المتحقق وحده، وفحوص الكود تعلّم.
- إعادة توليد الكشف الفارغ مرة واحدة، والفحوص الآلية (المشهد، الأسماء، الشكل، مدقق المخرجات).
- الحفظ في `journey_drafts` مع بيانات التوليد والعدادات.

**P1b — الإكمال**
- الحارس: قواعد الكود ثم البرومت المعتمد، بأربعة مخرجات. صيغ "هل يجوز / هل يجب / ما حكم" تُمرَّر للنموذج كإشارة ولا ترفض بذاتها. والتصحيحات الثلاثة (عيد ميلاد، اللباس، الصور).
- اشتقاق الإنجليزي والأوردو من العربي بعد اعتماد العربي، كل لغة ببصمتها واعتمادها.
- توليد الرحلات الأربع الباقية في الخلفية أثناء P2.

## P2 — شاشات الرحلة وأمر الاعتماد — 4 ساعات — tag: `p2-journey`

**المهام**
- الرئيسية بترتيب `when`: النشطة، ثم القادمة خلال 14 يومًا مع عدّاد، ثم الدائمة. ومكتبة بلا قفل.
- التقويم بـ`Intl` و`islamic-umalqura` و`Asia/Riyadh`، وباراميتر `date`.
- مشغّل الرحلة: المشهد، أربعة خيارات وخيار "غير ذلك"، الكشف ببطاقة المصدر (النص العثماني، المرجع، الشرح الموسوم)، اشرحها بكلماتك، نصيحة للدوام.
- خط يدعم علامات الرسم العثماني لنص الآيات (خط مجمع الملك فهد إن سمحت رخصته بالاستضافة، وإلا خط مفتوح الرخصة يغطي العلامات).
- قواعد العرض: المعتمد من الفريق فقط، مع الشارة. `needs_sharii` لا يُعرض بدون اعتماد شرعي. غير المعتمد يظهر في التطوير فقط بوسم أحمر.
- حفظ التقدم على الجهاز، وتسجيل الأحداث بلا هوية.
- أمر الاعتماد المبسّط `npm run approve -- --draft <id> --lang ar|en|ur --name <المراجع>`: يكتب في `review_decisions` باسم صاحب المشروع ودور الفريق وببصمة النص، لكل لغة ببصمتها. نفس مسار البيانات الذي ستستخدمه اللوحة في P5.

**شرط النجاح**
```bash
npm run check:font             # كل حروف وعلامات نصوص quran_verses موجودة في الخط
npm run check:approve          # اعتماد بالأمر يُظهر الرحلة؛ تعديل النص بعده يخفيها؛ اعتماد العربي لا يعتمد الإنجليزي
npm run test:e2e -- journey    # رحلة كاملة بالعربي ثم بالإنجليزي ثم بالأوردو
npm run check:when             # نفس حالات اختبار التقويم: 5 سنوات هجرية مقابل جدول أم القرى، 0 أخطاء
npm run check:invariants       # الثوابت الخمسة في data/invariants.json
```
الرابط المنشور يعرض "لا توجد رحلات معتمدة بعد" إلى أن تُعتمد رحلة بأمر الاعتماد. اختبار الرحلة يشتغل محليًا على مسودة بوسم غير معتمد.
