# Agent skills

Third-party tooling used by coding agents while working on this repo. It is not part of the Lahza application and is not shipped to users.

| Skill | Source | Version | License |
|---|---|---|---|
| `impeccable` | https://github.com/pbakaus/impeccable | 4.5.0 | Apache-2.0 (see `LICENSE-impeccable`) |

Installed unmodified with `npx skills add pbakaus/impeccable`; `skills-lock.json` in the repo root records the content hash.

In this project the skill is used to review and polish screens within the visual language of `design/lahza-prototype.html`, not to redesign them.
